ABOUT THE PROJECT

IoT-Based Smart Indoor Climate Monitoring System

A simple IoT system designed to monitor indoor temperature and humidity in real time.

PROJECT OVERVIEW

Smart Indoor Monitoring

The system uses a DHT11 temperature and humidity sensor connected to an ESP32 microcontroller. The ESP32 collects the sensor readings and transmits the data through Wi-Fi to the ThingSpeak IoT cloud platform.

The web dashboard provides a convenient interface for viewing current and historical environmental readings.
